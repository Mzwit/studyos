# StudyOS

Learn From Zero. Master Every Topic. Walk Into Exams Prepared.

A personal study and exam-preparation site for CSC411, CSC421 and CSC461 (University of Eswatini), hosted free on GitHub Pages.

- Lecture notes, page images and past papers are **AES-256-GCM encrypted** (`data/`, `img/*.bin`); the passcode decrypts them in the browser.
- AI features use the student's own free Google Gemini API key, stored only in their browser (Settings → AI connection).
- Progress is saved in each browser; use Settings → Export / Import to move it between devices.
